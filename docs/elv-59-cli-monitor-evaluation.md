# ELV-59 评估文档. CLI 当前会话上下文与用量终端常驻显示方案

## 1. 背景与目标

Antigravity CLI 用户在纯终端工作流中通常不打开 Antigravity 桌面客户端. 并且经常出现多个 CLI 终端同时运行或主会话派生子代理的场景.
核心需求如下.

1. 无需打开 Antigravity 桌面客户端或依赖 ASAR/CDP. 常驻展示当前会话已用上下文 Token. 可靠上下文上限与占用比例.
2. 多个 `agy` CLI 同时运行时能区分不同会话与工作区. 切会话或切模型后实时更新. 不把一个会话的数值串到另一个会话.
3. 上限未知. 日志缺失或数据过期时明确标示未知. 不编造默认值.
4. 绝不覆盖用户正在输入的命令行. 绝不破坏 `agy` 原生 TUI 光标布局或流式输出. 支持随时关闭.

## 2. 四种候选方案对比

| 维度 | 方案 A. 独立 Electron/GUI 窗口 | 方案 B. 独立原生 EXE 桌面工具 | 方案 C. 本地网页 (127.0.0.1 HTTP + SSE) | 方案 D. 非侵入式终端常驻伴随监视器 / 状态行 |
| --- | --- | --- | --- | --- |
| 是否脱离桌面客户端 | 是. 但仍依赖 GUI 桌面环境 | 是. 需额外编译与分发平台二进制 | 是. 需要占用本机回环端口与浏览器标签 | 是. 纯 Node.js CLI 在终端内直接运行 |
| 对 `agy` 原生 TUI 干扰度 | 零干扰 | 零干扰 | 零干扰 | 零干扰. 不包裹 `agy` 的 stdin/stdout |
| 多 CLI 并发支持 | 好. 可做多标签列表 | 好. 可做多标签列表 | 极好. 同屏多卡片与筛选最直观 | 好. 分屏/另一终端标签或单行状态条展示多会话并支持 `--session` 切换 |
| 跨平台与分发成本 | 高. 需随包携带或探测 Electron | 极高. Win/macOS/Linux 需分别构建签名 | 中. 零依赖 HTTP 服务但需浏览器切换焦点 | 极低. 零新增外部依赖. 全平台与现有 CLI 共用代码 |
| 终端内常驻直觉度 | 低. 需切出终端看独立窗口 | 低. 需切出终端看独立窗口 | 低. 需在终端和浏览器间来回切换 | 高. 可直接放在分屏窗格或底部窄终端内常驻刷新 |
| 复用到现有采集逻辑 | 需新建 IPC 桥接 | 需跨语言重写 protobuf/sqlite 解析 | 可直接复用 Node.js 采集模块 | 100% 直接复用 `meter-collector.js` 与 `meter-core.js` |

说明. 若直接在当前同一个 `agy` 进程里用 PTY 包装劫持 `stdin`/`stdout` 绘制底部固定行. 虽然看似单终端一体化. 但 Go/TUI 程序重绘全屏光标时会高频擦除或错位. 在 Windows ConPTY 与 macOS Terminal 下极易破坏用户交互输入和流式输出. 因此严禁采用 PTY 劫持式终端注入.

## 3. 推荐方案

推荐采用 **方案 D (非侵入式独立终端伴随监视器 `node cli.js monitor`) 作为首期最小可用版本**. 并在后续有复杂多会话拓扑可视化需求时叠加可选的 **方案 C (仅绑定 `127.0.0.1` 的轻量本地网页)**.

选择理由如下.

1. 安全隔离. `node cli.js monitor` 运行在独立终端窗格或分屏 (Windows Terminal / tmux / iTerm2 分屏) 中. 通过只读扫描 `~/.gemini/antigravity-cli` 会话目录与统一账本 `pricing_ledger_v1.json` 刷新显示. 绝不向 `agy` 进程注入字节. 绝不占用或干扰 `agy` 的终端输入流与流式渲染.
2. 多 CLI 天然隔离. 通过采集 `brain/<sessionId>/.system_generated/logs/transcript.jsonl`. `presence/<sessionId>.lock` 与账本内按 `cascadeId` 分组的 `source === 'cli'` 调用记录. 可同时列出所有并发 CLI 会话并标明工作区目录. 模型名与子代理来源. 支持 `--session <id>` 或 `--cwd <path>` 锁定当前关注会话.
3. 口径一致与零编造. 复用与桌面端及 `node cli.js usage` 一致的账本读取与上下文预算解析. 对未知上下文上限明确显示 `未知` 与 `--%`. 对历史旧会话标明 `idle` / `stale`.

## 4. 最小可用版本 (MVP) 规格

命令入口.

- `node cli.js monitor [--session <id>] [--cwd <dir>] [--compact] [--interval <ms>] [--once] [--json]`

核心能力.

1. 脱离桌面客户端独立运行. 不依赖 Electron. ASAR 或 CDP.
2. 列出并区分多 CLI 并发会话. 展示各会话上下文已用量. 可靠上限. 百分比. 模型. 会话累计 Token 与活跃状态.
3. 支持 `--compact` 单行常驻状态行与终端窗口标题 (OSC 0) 同步更新. 适配窄窗格常驻.
4. 支持 `--once` 单次快照输出与 `--json` 结构化输出. 方便脚本验证与自动化测试.
5. `Ctrl+C` 优雅退出并恢复终端状态. 无锁文件或后台进程残留.
