# v0.8.9 客户端插件 UI 精简与交互设计方案

> 状态. 设计稿 (仅设计, 暂不实现, 待确认后进入编码阶段).
> 适用范围. `src/renderer/template.html`、`src/renderer/styles.css`、`src/renderer/main.js`、`src/renderer/i18n.js` 及 `meter-collector.js` 设置存储.

---

## 1. 设计目标与问题诊断

当前 v0.8.x 客户端注入 UI 在功能快速叠加后出现以下问题.

1. 顶栏宽度与文字占用过重. 顶栏入口包含 6 个按钮 (`#badge-quota` `#badge` `#badge-speed` `#badge-tokens` `#badge-cli` `#badge-overflow`), 等待模型响应时 `#badge-speed` 展示 `等待 1s` / `Wait 1s` 秒跳文字造成横向抖动 (ELV-93).
2. 顶栏位置缺少用户可控选择. 目前仅通过 `ensureHostDocked()` 在 `data-dock="flow"` 与 `data-dock="fixed"` 之间自动切换, 窄分栏、全屏编辑或隐藏侧栏场景下容易遮挡原生标题栏控件或被裁切 (ELV-94).
3. 顶栏额度维度不可选. `#badge-quota` 强制采用 `selectPrimaryQuotaBucket()` 自动选最紧缩窗口, 用户无法固定关注 `5h` 短期窗口或 `weekly` 周窗口 (Issue #41).
4. 设置项与低频信息散落在多个面板顶部. 主面板 `#panel` 标题栏拥挤了多语言切换、`GitHub`、检查更新、调色板、主题切换、关闭等 6 组控件; 卡片内部叠加多层子卡与说明正文, 首屏信噪比下降.

精简核心原则. 顶栏只留高频状态与一键动作, 消除秒跳文字抖动. 面板内高频控件直接可达, 低频配置下沉或合并, 删除冗余重复展示元素, 保持全部功能零丢失.

## 3. 核心需求专项设计

### 3.1 ELV-94. 面板与顶栏停靠位置可选 (`dockPosition`)

#### 可选位置枚举与语义

按 ELV-94 规格将 `data-dock` 由现有的 `flow` / `fixed` 二态扩展为 **5 个显式位置选项** (存入 `uiPreferences.dockPosition`), 未显式覆盖或目标容器暂未挂载时按 `flow -> fixed` 自动回退.

1. `flow` (顶栏胶囊, 默认优先). 嵌入主对话标题栏右侧作为流式占位入口, 点击弹出主面板 `#panel` 浮层, 自动避让 Windows WCO 窗口控制区.
2. `fixed` (现有右上角悬浮). 始终以 `position: fixed` 悬浮于视口右上角 (自动避让 WCO 与滚动条), 面板以浮层弹出, 不修改宿主标题栏 DOM 树.
3. `aux` (停靠右侧辅助栏). 作为**占位元素 (`position: static`)** 直接挂载进 Antigravity 右侧辅助栏容器内部 (如 `[data-testid="toggle-aux-sidebar"]` 对应面板区或辅助栏面板体), 面板主体直接常驻展开而不必依赖顶栏胶囊触发.
4. `page` (编辑器区整页). 作为**占位元素 (`position: static`)** 挂载到主工作区 / 编辑器分栏容器内部以整页宽度展开 (类似独立标签页体验), 适配大屏多维数据同时平铺查看.
5. `hide` (隐藏顶栏与面板). 隐藏顶栏胶囊主组, 仅保留命令行或快捷触发入口/极简唤醒点, 避免占屏.

#### 占位逻辑 vs 浮层逻辑界定

| 模式 | CSS 定位模型 | 是否占据宿主文档流空间 | 触发条件与避让策略 |
| :--- | :--- | :--- | :--- |
| `flow` (占位胶囊 + 浮层面板) | 胶囊 `position: static` / 面板 `fixed` | **胶囊是** (写入标题栏右侧) / **面板否** | `ResizeObserver` 监听标题栏可用宽度触发 `full -> compact -> ring-only` 三档; 激活 WCO 时增加右侧安全边距 |
| `fixed` (纯浮层模式) | `position: fixed` (`z-index: 2147483000`) | **否** (挂载于 `document.body`) | 根据 `navigator.windowControlsOverlay?.getTitlebarAreaRect()` 计算顶部安全区, 面板向左/向下动态翻转不超视口 |
| `aux` (辅助栏占位) | `position: static` / `display: block` (`width: 100%`) | **是** (写入辅助栏 DOM 子树) | 必须使用原生流式占位盒模型而非悬浮遮罩; 若右侧辅助栏被折叠或未找到容器, 临时回退 `fixed` 并提示 |
| `page` (编辑器整页占位) | `position: static` / `display: flex; flex: 1` | **是** (占据主编辑器内容容器) | 同一套 `#view-context` / `#view-tokens` / `#view-quota` 内容视图自适应整页双栏网格; 未匹配主分栏时回退 `fixed` |
| `hide` (隐藏) | `display: none` / 20px 边缘恢复点 | **否** | 从配置页、快捷键或 `cli` 可随时切回可见模式 |

持久化键值. `settings.uiPreferences.dockPosition` (并通过 `localStorage` `ag_dock_position` 做首帧防闪烁预读取).

### 3.2 Issue #41. 顶栏额度显示可选 (`auto` / `5h` / `weekly` / `both`)

#### 问题分析

共享额度池 (如 Gemini / Claude 额度池) 经常同时返回多个重置周期的桶 (bucket): 短周期 `5h` 滑动窗口与长周期 `weekly` (7d) 窗口. 当前 `selectPrimaryQuotaBucket()` 强制选剩余比例最小者, 在某些场景下用户可能只关心 `5h` 小窗口是否将耗尽, 或更关心 `weekly` 周总额度是否见底.

#### 方案设计

在 `uiPreferences` 新增 `quotaBadgeWindowMode`, 可选 4 种模式 (默认 `auto`).

1. `auto` (最紧缩优先, 默认). 保持现行规则: 在可用周期中优先展示剩余率最低的窗口, 并在角标 `#quota-badge-tag` 标注窗口短标 (`5h` 或 `7d` 当且仅当非主直觉窗口时).
2. `5h` (固定显示 5 小时窗口). 顶栏圆环与 `#quota-badge-val` 锁定展示 `5h` 窗口余量; 若当前模型池仅有单窗口 (无 5h 区分), 自动回退显示该唯一窗口.
3. `weekly` (固定显示周窗口). 顶栏圆环与 `#quota-badge-val` 锁定展示 `7d` / `weekly` 窗口余量; 若当前池无周窗口, 回退展示唯一窗口并在角标标注实际窗口名.
4. `both` (双行微缩模式). 顶栏仅保留一个圆环 (颜色跟随后紧缩者), 右侧指标区上下双行微缩字号显示 `5h 92%` / `7d 68%` (仅当当前池同时存在 5h 与周窗口时启用, 单窗口自动退回单行).

交互入口.
- 设置 tab 「顶栏与外观」卡片提供 4 选 1 分段控件 (`自动(最紧缩)` / `5h 窗口` / `周额度` / `双窗口`).
- 快捷操作. 右键点击或按住 `Alt + 点击` 顶栏 `#badge-quota` 时可在 `auto -> 5h -> weekly` 间快速轮切并在 Tooltip 首行显示当前锁定模式.

### 3.3 ELV-93. 等待状态改为纯动效 (去除 `等待 1s` 文字抖动)

#### 问题定位

`src/renderer/main.js` 第 10987-10989 行在 `evalRes.phase === 'waiting'` 时写入 `speedAmount.textContent = "等待 1s"` / `"Wait 1s"`, 每秒字符长度或等宽变化引发按钮轻微重排与视觉焦虑.

#### 方案设计

1. **顶栏 `#badge-speed` 改为固定宽度纯 SVG 沙漏动效**:
   - 等待阶段 (`evalRes.phase === 'waiting'`) 隐藏读秒文本 (`#speed-amount` 置空或保持极窄固定占位), 在 `#badge-speed-icon` 槽位内渲染 14x14px 矢量沙漏 SVG, 保持按钮总体尺寸平稳.
   - **动效结构 (CSS GPU 合成属性驱动, 零主线程重排)**:
     - 动画周期 `1.8s` 循环:
       - `0% - 65%`. 沙漏静止竖立, 上腔沙粒三角形路径通过 `clip-path` / `scaleY` 向下收缩, 下腔沙粒向上堆积, 中央 1px 落沙流虚线向下平移 (`translateY`).
       - `70% - 100%`. 外框 `<svg>` 执行 180 度缓动翻转 (`transform: rotate(180deg)` with `cubic-bezier(0.4, 0, 0.2, 1)`), 随后无缝接续下一周期.
     - 只动画化 `transform` 与 `opacity`, 符合复合层性能预算, 避免触发 Layout/Paint.
   - **无障碍与悬停可读性**:
     - `title` 与 `aria-label` 仍同步真实已等待时长 (如 `正在等待首字返回 · 已等待 3s`), 键盘读屏用户与悬停鼠标时可随时看到精确等待时间.
   - **`prefers-reduced-motion: reduce` 降级**:
     - 检测到系统减弱动态效果时, 停止翻转与落沙动画, 改为静态居中沙漏图标 + 低频呼吸透明度微弱变化或纯静态展示.
2. **展开面板 `#pane-ctx-session` 内的 `#speed-summary` 卡片处理**:
   - 卡片标题闪电位同步显示沙漏图标, 4 格数值第一格 `#speed-val` 从 `等待首字` 改为纯沙漏小动画 + 可选灰色小角标耗时 (`3s` 放在辅助字段 `#speed-duration` 中), 保持顶栏干净的同时不丢失详细观测数据.
